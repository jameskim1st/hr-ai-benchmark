# Docebo AI Learning — La-Z-Boy + Disguise + Brooks

## Summary

Docebo는 **AI-native로 전환 중인 LMS/LXP** (3,900+ 대형 고객, 상장사) — **Josh Bersin**(Tier 1)의 2025-06 독립 분석에서 "transitioning to AI-native"로 분류 [[sources/bersin-ld-revolution-2025-06]]. Bersin이 Project Harmony(neural search), dynamic content generation, virtual coaching(beta), use-case instructional templates, collaborative content design을 확인 [[sources/bersin-ld-revolution-2025-06]]. Docebo 제품 페이지는 AI 콘텐츠 생성 도구 **Docebo Creator**(수 초 내 인터랙티브 콘텐츠·학습 계획 생성)를 소개 [[sources/docebo-learning-platform-page-2026-09]]. 고객 사례: ⚠️ 벤더 주장 — **Brooks Automation** 교육 시간·비용 20% 절감 [[sources/docebo-customers-page-2026-09]]. **La-Z-Boy**·**Disguise** 사례의 수치(활성 사용자 증가율·완료율·learner 배수·학습 수익)는 현재 인용 소스 어디에도 없어 _미공개 (not disclosed)_ (2026-09-27 grounding 점검 — 개별 사례 페이지 미확보).

## Problem / Why (도입 배경)

- **Before (baseline)**: ❓ baseline 미공개 — La-Z-Boy의 도입 전 LMS 상태(기존 시스템 연식·engagement·콘텐츠 제작 기간)는 인용 소스에 없음.
- **Pain point**: ⚠️ 벤더 주장(제품 페이지, 고객 공통): 다중 대상(직원·고객·파트너) 학습을 한 플랫폼에서 관리하고 GenAI로 콘텐츠를 대규모 생성할 필요 [[sources/docebo-learning-platform-page-2026-09]]. 시장 맥락: 전통 SCORM "publishing" 모델에서 AI 생성 dynamic content로 이동 [[sources/bersin-ld-revolution-2025-06]].
- **Trigger**: _미공개 (not disclosed)_ — La-Z-Boy의 도입 결정 계기는 소스에 없음.
- 🚫 일반론 표기: 벤더 제품이므로 특정 기업의 도입 배경은 고객별 상이.

## Consulting Angle

### 핵심 가치
- **"기존 LMS를 AI-native로 교체"하는 migration 사례의 대표**: La-Z-Boy의 outdated LMS → Docebo 전환 성과 수치는 현재 _미공개_ — 개별 사례 페이지 확보 후 **한국 기업의 LMS 교체 프로젝트** reference로 활용
- **Bersin Galileo Learn과의 대비**: Galileo는 "처음부터 AI-native"이고 고객 극소수, Docebo는 "전통 → AI 전환"이고 3,900+ 고객. **Risk-averse 한국 대기업**에는 Docebo 경로가 더 현실적
- **Disguise 사례의 "SCORM → microlearning" 전환**: 전환 수치 _미공개_ (인용 소스에 없음) — 시장 narrative(SCORM publishing → AI dynamic content)는 Bersin이 확인 [[sources/bersin-ld-revolution-2025-06]]

### 한국 적용
- 국내 대기업 LMS: 삼성 멀티캠퍼스, 휴넷, 더존 러닝 등이 사용 중 — Docebo처럼 AI 전환 중인 곳이 있는지 조사 필요
- 한국어 콘텐츠 품질·법정교육(산업안전·성희롱 예방 등) 자동 생성 대응력이 핵심 fit 판단 기준
