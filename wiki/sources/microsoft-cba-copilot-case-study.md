# Commonwealth Bank of Australia invests in AI skills and Microsoft Copilot to drive innovation

## Summary
Microsoft 고객 사례. CBA는 'AI for All' 스킬링 프로그램(Leading/Working/Building with AI 3개 경로)을 운영하며 Microsoft Learn·ESI·AI Academy를 활용. Microsoft 365 Copilot 사용자 10,000명 중 84%가 "없이는 일하지 못한다"고 응답, 초기 사용자 16% 시간 절감, GitHub Copilot 코드 제안 약 30% 채택. HR 학습·스킬링 리드 Jane Adams 인용.
