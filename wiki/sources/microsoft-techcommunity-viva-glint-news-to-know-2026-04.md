## Summary

Microsoft Viva Glint 공식 월간 뉴스레터 2026-04호. Copilot Highlights GA: Team Summary·Executive Summary 리포트 안에 강점·기회·점수 변화·benchmark 비교를 AI 요약으로 자동 생성, 다국어 지원, 코멘트 요약보다 낮은 응답자 수 조건에서 동작. 2026-04-30부터 Viva Glint Copilot 제어가 M365 Admin Center로 이관되며 기존 admin toggle 제거, 플랫폼 레벨 default ON. 그 외 Copilot 측정 문항 7개 추가(총 21문항), R/Python 패키지, Employee Feedback Agent preview 등.

## Key Quotes

> Copilot reporting: Copilot Highlights. Copilot Highlights, now generally available, generates AI-powered summaries of employee survey results directly within Team Summary and Executive Summary reports, surfacing key insights like strengths, opportunities, score changes, and benchmark comparisons so managers and leaders can move from data to action faster.

> Unlike Copilot comment summarization, which requires a higher number of survey respondents, Copilot Highlights works wherever managers already have access to dashboard data, making Copilot in Viva Glint valuable for a broader set of leaders across your organization.
