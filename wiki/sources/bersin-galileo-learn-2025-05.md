# Source Summary — Bersin's Galileo Learn Launch (2025-05-21)

> ⚠ **Tier 분류 주의**: Josh Bersin은 일반적으로 Tier 1 HR 분석가이지만, **이 글은 본인 회사가 파는 제품 런칭 문서**이므로 Tier 3 (벤더 1차 소스)로 분류합니다. Bersin의 다른 일반 분석 글(독립적인 HR 트렌드 분석)과 구분해야 함.

## 요약
Josh Bersin Co.가 자사의 AI-native 기업 학습 플랫폼 Galileo Learn을 발표한 런칭 포스트. Galileo agent(Bersin Co.의 기존 AI 어시스턴트)의 학습 도메인 확장. 전통 LMS/LXP를 대체 지향.

## 벤더 주장 (⚠️)

### Product
- "AI-native learning platform tightly integrated into Galileo agent"
- 콘텐츠 입력: PDF, Word, 오디오, 비디오, SCORM — AI가 자동으로 코스·assessment·프로그램·exercise·simulation 생성
- AI 튜터, 아바타, 음성/텍스트 지도, "AI Josh" persona 기반 시나리오

### Architecture
- ⚠️ 벤더 주장: **Sana Labs AI foundation** 기반 (Sana Labs = OEM 파트너)
- Galileo agent의 사이드 패널로 업무 중 접근

### Data / Scale
- ⚠️ 벤더 주장: 700+ 코스, 96-level HR Capability Model 매핑
- ⚠️ 벤더 주장: 50+ L&D 리더 인터뷰 + 대규모 설문 기반 연구
- ⚠️ 벤더 주장: 60+ 언어 자동 번역

## Fact (공개된 객관 정보)

- ✅ Pricing: $495/year per person ($49/월), $200 add-on for existing Galileo users
- ✅ Bersin 본인 회사 내부 적용: 8년 된 온라인 HR academy를 5개월에 Galileo Learn으로 전환, **750 learning objects 생성**
- ✅ 이 재전환 사례가 **현재 공개된 유일한 customer deployment**
