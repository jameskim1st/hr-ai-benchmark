## Summary

HR Brew(Tier 2)가 Workday DevCon 2026에서 발표된 Sana for Workday 통합을 보도. Workday가 2025-11에 $1.1B로 Sana(스웨덴 AI-native LMS) 인수, 2026-03-17에 첫 통합 제품 공개. Sana의 conversational interface가 Workday 신규 UI front door로 채택. Sana Learn은 AI-native LMS 기능을 Workday Learning에 추가.

## Key Claims

- Sana for Workday: Workday 신규 UI front door (대화형 인터페이스)
- Sana Learn: AI-native LMS — ⚠️ 벤더 주장 코스 생성 4개월 → 4일, ⚠️ 벤더 주장 engagement 275% lift
- 30+ 언어 지원, 멀티모달(텍스트·비디오·음성)
- Workday Agent System of Record(ASOR)와 결합 — 학습 에이전트도 거버넌스 대상
- Sana 기존 고객(Klarna, MTV, Polestar)도 Workday 마이그레이션 경로 제공

✅ Tier 2 (HR Brew). 독립 보도이나 벤더 주장 수치는 그대로 인용 (HR Brew의 자체 검증 없음). Bersin 별도 분석([Workday + Sana strategy](https://joshbersin.com/2026/03/workday-and-sana-unveil-a-bold-new-strategy-for-ai/))이 Tier 1 보강.
