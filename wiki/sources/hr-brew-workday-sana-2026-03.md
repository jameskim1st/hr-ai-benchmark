## Summary

HR Brew(Tier 2, Adam DeRose, 기사 표기 2026-03-18)가 Workday의 Sana for Workday 출시 발표(화요일 발표, 프레스콜)를 보도. 원문 기준 Sana 인수는 "September", 이번 발표는 기존 핵심 제품의 대체가 아닌 AI-native 기능 추가. 구성은 Sana for Workday(자연어 인터페이스), Sana Self-Service Agent(프로세스·워크플로 자동화, 얼리어답터 고객 테스트, 300+ skills), Sana Enterprise(Workday 외부 시스템까지 에이전트 행동 범위 확장). CEO Aneel Bhusri와 제품·기술 사장 Gerrit Kazmaier 발언 인용. 2026-10-19 Aside로 원문 확보

## Key Claims

- Sana for Workday: Workday 내 신규 AI 인터페이스, HR 리더가 자연어로 시스템과 상호작용 (✅ 원문 확인)
- Sana Self-Service Agent: 프로세스·워크플로 자동화, 얼리어답터 고객 테스트 완료, 300+ skills (⚠️ 벤더 주장, 원문 확인)
- Sana Enterprise: Workday 외부 시스템과 연결해 더 포괄적인 행동 수행 (⚠️ 벤더 주장, 원문 확인)
- Sana Learn: AI-native LMS, 코스 생성 4개월 → 4일, engagement 275% lift (⚠️ HR Brew 원문에 없음, 2026-10-19 확인)
- 30+ 언어 지원, 멀티모달(텍스트·비디오·음성) (⚠️ HR Brew 원문에 없음)
- Workday Agent System of Record(ASOR)와 결합 (⚠️ HR Brew 원문에 없음, ASOR 언급 자체 없음)
- Sana 기존 고객(Klarna, MTV, Polestar) 마이그레이션 경로 (⚠️ HR Brew 원문에 없음)

## Key Quotes

> Workday announced this week its “next chapter” in its AI-enabled future: the launch of Sana for Workday, with new AI capabilities inside the Workday ecosystem aimed at helping users better interact with the platform for streamlined activity and through easier, more natural interactions.

→ 뒷받침하는 주장: Sana for Workday 출시, Workday 내부의 신규 AI 상호작용 계층

→ 뒷받침하는 주장: 인수 시점(원문 기준 September), 기존 제품 대체가 아닌 기능 추가

It also launched Sana Self-Service Agent, which can be used to automate processes and workflows. This agentic feature has already been tested by early-adopter customers and knows more than 300 skills that can dramatically change human workflows through automated processes across Workday.

→ 뒷받침하는 주장: 자연어 인터페이스, Self-Service Agent의 300+ skills와 얼리어답터 테스트 (⚠️ 벤더 주장)

→ 뒷받침하는 주장: Sana Enterprise의 Workday 외부 행동 범위

> “How we think about that is that Sana and Sana applications are the last software that people have to learn, because it’s the first software that’s going to learn you and how you get work done every day,” he added.

→ 뒷받침하는 주장: Gerrit Kazmaier(president of product and technology)의 제품 포지셔닝 발언
