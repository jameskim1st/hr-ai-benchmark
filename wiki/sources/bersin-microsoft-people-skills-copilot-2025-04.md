## Summary

Josh Bersin가 2025-04-23 Microsoft의 Copilot 발표 중 HR에 의미 있는 People Skills(스킬 추론 에이전트 + 스킬 관리 에이전트)를 분석. MS Copilot·M365 라이선스 고객의 직원 스킬을 사용자 프로필·활동 기반으로 자동 추론해 커스터마이즈 가능한 taxonomy에 매핑하고, Skills Agent가 Copilot Chat·M365·Viva에 데이터를 공급. LinkedIn taxonomy와 매핑. Bersin은 Workday Skills Cloud·Eightfold·Gloat·Techwolf 등 스킬 플랫폼이 commoditize될 수 있다고 전망. 컴필레이션(us-large-enterprise-hr-ai-2025-2026)에 기재된 URL은 404이며, 본 페이지 URL('-in-copilot-' 포함)이 실제 게시물.

## Key Quotes

> But one feature set that is significant to HR is Microsoft’s new skills infrastructure: a skills-inference agent (and a skills management agent) that lets companies identify and monitor the skills of all their employees.

→ 뒷받침하는 주장: People Skills = 스킬 추론 에이전트 + 스킬 관리 에이전트 구조

> How does it work? MS People Skills infers individual’s skillsets from user profiles and activity mapped to a customizable taxonomy. This data layer fuels the Skill Agent, which feeds Copilot Chat, Microsoft 365, and Viva services.

→ 뒷받침하는 주장: 직원 활동 기반 스킬 자동 추론 → Skills Agent 데이터 레이어

> For LinkedIn users, the taxonomy is mapped to LinkedIn’s taxonomy. This means all employees can use consolidate their profiles and skills between LinkedIn and their internal profiles.

→ 뒷받침하는 주장: LinkedIn taxonomy 매핑 (use case의 'LinkedIn 공동 개발 taxonomy' 주장의 근거 — 단 16,000 스킬 수치는 본 기사에 없음)

> If Microsoft does this within the Microsoft Graph, it may compete with or even overtake these other platforms because of its large data set. So over time, if Microsoft invests in this technology, some of these players become commoditized.

→ 뒷받침하는 주장: HR Tech 시장 disrupt 전망 (Bersin 분석 의견)
