# Source Summary — Paradox Clients Page (fetched 2026-04-12)

## 요약
Paradox의 공식 고객 레퍼런스 페이지. 40+ 기업의 case study와 metric이 나열된 **벤더 자체 마케팅 콘텐츠**. 각 수치는 Paradox 자체 주장이며 독립 검증·측정 방법론 공개 없음.

## 주요 metric 보유 레퍼런스 (⚠️ 벤더 주장)

### 식음료·소매 (Paradox의 주력 버티컬)
- **Chipotle**: 75% time-to-hire 감소
- **7-Eleven**: 50% time-to-hire 감소, 주 40,000시간 절약
- **Checkers & Rally's**: 9일 → 4분 미만 스케줄링, 연 35,000시간 절약
- **Captain D's**: 75% 이직률 감소, YoY 33% 공석 감소
- **Sodexo**: 60% time-to-fill 감소
- **Flynn Group**: 13~14일 → 4일 time-to-hire, 90% 프로세스 자동화

### 대기업·제조
- **General Motors**: 연 $2M 절약 (인터뷰 자동화)
- **Johnson Controls**: 89% 지원 완료율, 190,000 질문 답변
- **Medtronic**: 3개월간 6,000 인터뷰, 2~3일 → 17분 스케줄

### 헬스케어
- **Essentia Health**: 스케줄된 인터뷰 100% 증가
- **Houston Methodist**: hard-to-fill 역할 30% 증가

### 기술 기업 (흥미로운 교차)
- **Workday**: 2년간 23,000시간 절약 (Workday 자체 채용팀이 Paradox 사용)
- **Dell**: 2~3시간 → 30초~1분 per 후보자
- **Altice USA**: 스케줄링 시간 50% 감소

### 고비용 절약 주장
- **TruGreen**: 12주간 $1.8M 절약
- **Great Wolf Lodge**: $700k 절약
- **The Saxton Group**: 연 $270k+ 절약

## 이 소스의 신뢰성 한계

- **모든 수치가 Paradox 자체 주장**: Tier 3 (vendor-primary)
- **독립 검증 없음**: 어떤 Tier 1·2 매체도 이 수치들을 독립 확인하지 않음
- **측정 방법 미공개**: "time-to-hire 75% 감소"의 기준점·비교 기간·계산 방식 불명
- **Publication date 미기재**: 각 case study가 언제 수집됐는지 알 수 없어 stale 여부 판단 불가
- **일관된 패턴**: 거의 모든 case가 "자동화로 시간·비용 절약"이라는 단일 메시지. 실패·한계·예외 언급 없음
