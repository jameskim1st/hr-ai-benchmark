# Businessolver Expands Sofia’s Agentic AI Framework with Powerful New Insights Agent and Industry-Leading AI Safeguards

## Summary
Businessolver가 2025-07-17 발표한 보도자료. 자체 AI 엔진 Sofia의 agentic 프레임워크를 Intake Agent(질문 분류·에스컬레이션 판단), Answer Agent(플랜 문서 기반 응답), QA Agent(응답 품질 검증), Insights Agent(HR 리더용 데이터 기반 권고)로 구성. Answer Agent는 83% 7일+ 해결률과 연 170만 건 이상 고유 질문 처리를 뒷받침한다고 주장.

## Key Quotes
> Posted on Thursday, July 17, 2025

→ 뒷받침하는 주장: 발표 시점 2025-07

> - Intake Agent acts as the first line of intelligence in Sofia’s conversational workflow. It doesn’t just interpret questions, it helps ensure they’re handled appropriately. Through real-time analysis, it determines whether to clarify, escalate, deflect, or proceed, depending on the nature and urgency of the inquiry.

→ 뒷받침하는 주장: Intake Agent 역할

> - Answer Agent delivers precise and contextually accurate responses by reading data pre-loaded into Sofia’s knowledge base, including eligibility and plan documents, supporting Sofia’s 83% 7+-day resolution rates, supporting over 1.7M unique questions annually.

→ 뒷받침하는 주장: Answer Agent·83% 해결률·1.7M 질문

> - Quality Assurance (QA) Agent conducts rigorous QA on all responses to ensure factual accuracy, clarity, and relevance to the original query with Sofia.

→ 뒷받침하는 주장: QA Agent 존재(use case의 3-agent 구조와 달리 4개 agent)


## Limitations
벤더 보도자료 — 수치는 자사 측정. use case는 'Intake/Answer/Insights 3개 agent'로 기술하나 원문은 QA Agent 포함 4개. 문서 자동 검증 수치는 이 자료에 없음.
