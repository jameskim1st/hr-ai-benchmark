## Summary

Toshiba deployed Microsoft 365 Copilot to 10,000 employees as part of its "Toshiba Revitalization Plan" (FY2024–FY2026). Piloted with 400 employees first; measured via Viva Insights. Published as Microsoft customer story (Tier 3 — vendor primary). No independent Tier 1/2 analysis of Toshiba-specific metrics found.

## Key Results

| Metric | Value | Source |
|---|---|---|
| Employees covered | 10,000 | Microsoft customer story |
| Pilot group | 400 employees | Microsoft customer story |
| Pilot adoption rate | 95% active use | Microsoft customer story |
| Time savings per employee/month | **5.6 hours** confirmed | Microsoft customer story |
| Estimated annual savings (10k employees) | 200,000+ hours/year | Derived from above |
| Top use cases | Teams meeting recordings, PowerPoint docs, email/meeting catch-up | Microsoft customer story |

Note: The 5.6 hours/month figure is ⚠️ 자사 보고 (Toshiba's own confirmation via Microsoft case study format). No independent audit found.

## Implementation Approach

- Trial with 400 employees to establish usage patterns and maximize effectiveness
- Combined Microsoft 365 usage logs with Viva Insights (work pattern analytics)
- Created automated system recommending Copilot use cases based on individual activity patterns
- Context: Toshiba Revitalization Plan aims for business transformation, cost reduction, and strategic shift
